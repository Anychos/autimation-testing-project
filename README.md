# Практика автоматизации тестирования

Учебный проект для отработки навыков автоматизации тестирования и развития практики работы с тестовой инфраструктурой.

## Что планируется автоматизировать

- **API:** критические сценарии работы приложения.
- **UI:** сквозные end-to-end сценарии, которые проверяют пользовательские пути через интерфейс.

## Инструменты

- **Python и pytest** — написание и запуск тестов.
- **Playwright** — автоматизация браузера.
- **HTTPX** - автоматизация API.
- **Pydantic** — описание и проверка данных.
- **Faker** — генерация тестовых данных.
- **Ruff** — проверка качества кода.

## Smoke-тесты в GitHub Actions

При каждом push workflow запускает тесты с маркировкой `smoke`. Он получает
[репозиторий приложения](https://github.com/Anychos/autimation-testing-project-app),
поднимает backend и PostgreSQL через Docker Compose и запускает `python -m pytest -m smoke`.
Результат и логи доступны во вкладке Actions репозитория тестов.

## Структура проекта

```text
assertions/         Переиспользуемые проверки результатов тестов
clients/            API-клиенты и создание HTTP-клиентов
fixtures/           Фикстуры pytest для подготовки тестовых данных и клиентов
schemas/            Pydantic-схемы запросов и ответов
tests/              Тестовые сценарии
tools/              Вспомогательные инструменты и генерация данных
.env.example        Пример переменных окружения
config.py           Настройки проекта
conftest.py         Подключение общих фикстур pytest
pytest.ini          Настройки pytest
requirements.txt    Зависимости проекта
```
